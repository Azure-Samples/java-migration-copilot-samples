# Design Patterns

## Identified Patterns
- **MVC:** All web applications
- **Repository:** Spring Data JPA projects
- **Service Layer:** Spring Boot projects
- **Factory:** Malshinon
- **Strategy:** asset-manager (StorageService implementations)
- **Template Method:** asset-manager worker (AbstractFileProcessingService)
- **Dependency Injection:** Spring, limited ASP.NET MVC
