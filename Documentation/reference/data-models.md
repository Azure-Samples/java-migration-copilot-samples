## Java Entity Models

### asset-manager Entities

#### 1. ImageMetadata

**Purpose:** Stores metadata about uploaded images in PostgreSQL  
**Table:** `image_metadata`  
**ORM:** JPA/Hibernate  
**Locations:** 
- Web: `asset-manager/web/src/main/java/com/microsoft/migration/assets/model/ImageMetadata.java`
- Worker: `asset-manager/worker/src/main/java/com/microsoft/migration/assets/worker/model/ImageMetadata.java`

**Entity Definition:**
```java
@Entity
@Table(name = "image_metadata")
@Data
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class ImageMetadata {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;
    
    @Column(name = "key", unique = true, nullable = false)
    private String key;              // S3 object key (unique identifier)
    
    @Column(name = "filename")
    private String filename;         // Original filename
    
    @Column(name = "file_size")
    private Long fileSize;           // Size in bytes
    
    @Column(name = "content_type")
    private String contentType;      // MIME type (e.g., "image/jpeg")
    
    @Column(name = "uploaded_at")
    private LocalDateTime uploadedAt; // Upload timestamp
    
    @Column(name = "thumbnail_key")
    private String thumbnailKey;     // S3 key for thumbnail (generated by worker)
    
    @Column(name = "status")
    private String status;           // Processing status (e.g., "PENDING", "COMPLETED")
}
```

**Database Schema:**
```sql
CREATE TABLE image_metadata (
    id BIGSERIAL PRIMARY KEY,
    key VARCHAR(255) UNIQUE NOT NULL,
    filename VARCHAR(255),
    file_size BIGINT,
    content_type VARCHAR(100),
    uploaded_at TIMESTAMP,
    thumbnail_key VARCHAR(255),
    status VARCHAR(50)
);
```

**Lifecycle:**
1. Created when file uploaded to S3
2. `thumbnailKey` populated by worker after processing
3. `status` updated through processing stages

### todo-web-api Entities

#### TodoItem

**Purpose:** Todo/task item entity  
**Table:** `TODO_ITEMS`  
**Database:** Oracle Database  
**ORM:** JPA/Hibernate  
**Location:** `todo-web-api-use-oracle-db/src/main/java/com/microsoft/migration/todo/model/TodoItem.java`

**Entity Definition:**
```java
@Entity
@Table(name = "TODO_ITEMS")
@Data
@NoArgsConstructor
@AllArgsConstructor
public class TodoItem {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    @Column(name = "ID")
    private Long id;
    
    @Column(name = "TITLE", nullable = false, length = 200)
    @NotBlank(message = "Title is required")
    @Size(max = 200, message = "Title must be less than 200 characters")
    private String title;
    
    @Column(name = "DESCRIPTION", length = 4000)
    @Size(max = 4000, message = "Description must be less than 4000 characters")
    private String description;
    
    @Column(name = "COMPLETED")
    private boolean completed;       // Default: false
    
    @Column(name = "PRIORITY")
    private int priority;            // Numeric priority (higher = more important)
    
    @Column(name = "DUE_DATE")
    private LocalDateTime dueDate;   // Optional due date
    
    @Column(name = "CREATED_AT", nullable = false, updatable = false)
    private LocalDateTime createdAt;
    
    @Column(name = "UPDATED_AT")
    private LocalDateTime updatedAt;
    
    @PrePersist
    protected void onCreate() {
        createdAt = LocalDateTime.now();
        updatedAt = createdAt;
    }
    
    @PreUpdate
    protected void onUpdate() {
        updatedAt = LocalDateTime.now();
    }
}
```

**Oracle-Specific Features:**
- Uses Oracle `VARCHAR2` for string columns (via length constraints)
- Identity generation compatible with Oracle sequences
- Supports Oracle's extended VARCHAR2 lengths (up to 4000 for description)

**Database Schema (Oracle):**
```sql
CREATE TABLE TODO_ITEMS (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    TITLE VARCHAR2(200) NOT NULL,
    DESCRIPTION VARCHAR2(4000),
    COMPLETED NUMBER(1) DEFAULT 0,  -- Boolean as 0/1
    PRIORITY NUMBER,
    DUE_DATE TIMESTAMP,
    CREATED_AT TIMESTAMP NOT NULL,
    UPDATED_AT TIMESTAMP
);
```

**Validation:**
- Title: Required, max 200 chars
- Description: Optional, max 4000 chars
- Completed: Defaults to false
- Timestamps: Automatically managed

### ContosoUniversity Entities

#### 1. Student

**Purpose:** Student entity with enrollments  
**Table:** `Student`  
**Database:** SQL Server  
**ORM:** Entity Framework 6  
**Location:** `ContosoUniversity/Models/Student.cs`

**Entity Definition:**
```csharp
public class Student : Person
{
    [Required]
    [DataType(DataType.Date)]
    [DisplayFormat(DataFormatString = "{0:yyyy-MM-dd}", ApplyFormatInEditMode = true)]
    [Display(Name = "Enrollment Date")]
    [Column(TypeName = "datetime2")]
    [Range(typeof(DateTime), "1/1/1753", "12/31/9999", 
           ErrorMessage = "Enrollment date must be between 1753 and 9999")]
    public DateTime EnrollmentDate { get; set; }
    
    // Navigation property
    public virtual ICollection<Enrollment> Enrollments { get; set; }
}

// Inherited from Person (abstract base class)
public abstract class Person
{
    public int ID { get; set; }
    
    [Required]
    [StringLength(50)]
    [Display(Name = "Last Name")]
    public string LastName { get; set; }
    
    [Required]
    [StringLength(50, MinimumLength = 1)]
    [Display(Name = "First Name")]
    public string FirstMidName { get; set; }
    
    [Display(Name = "Full Name")]
    public string FullName 
    { 
        get { return LastName + ", " + FirstMidName; } 
    }
}
```

**Database Schema:**
```sql
CREATE TABLE [dbo].[Student] (
    [ID] INT IDENTITY(1,1) PRIMARY KEY,
    [LastName] NVARCHAR(50) NOT NULL,
    [FirstMidName] NVARCHAR(50) NOT NULL,
    [EnrollmentDate] DATETIME2 NOT NULL,
    CONSTRAINT CK_EnrollmentDate CHECK (EnrollmentDate >= '1753-01-01' 
                                        AND EnrollmentDate <= '9999-12-31')
);
```

**Validation Rules:**
- LastName: Required, max 50 chars
- FirstMidName: Required, 1-50 chars
- EnrollmentDate: Required, must be valid datetime2 range (1753-9999)
- SQL Server datetime validation enforced in controller

**Relationships:**
- One Student → Many Enrollments

#### 4. Enrollment

**Purpose:** Junction table for Student-Course many-to-many relationship  
**Table:** `Enrollment`  
**Location:** `ContosoUniversity/Models/Enrollment.cs`

**Entity Definition:**
```csharp
public enum Grade
{
    A, B, C, D, F
}

public class Enrollment
{
    public int EnrollmentID { get; set; }  // Primary key
    
    public int CourseID { get; set; }      // Foreign key
    public int StudentID { get; set; }     // Foreign key
    
    [DisplayFormat(NullDisplayText = "No grade")]
    public Grade? Grade { get; set; }      // Nullable enum
    
    // Navigation properties
    public virtual Course Course { get; set; }
    public virtual Student Student { get; set; }
}
```

**Database Schema:**
```sql
CREATE TABLE [dbo].[Enrollment] (
    [EnrollmentID] INT IDENTITY(1,1) PRIMARY KEY,
    [CourseID] INT NOT NULL,
    [StudentID] INT NOT NULL,
    [Grade] INT NULL,  -- Nullable: NULL, 0=A, 1=B, 2=C, 3=D, 4=F
    CONSTRAINT FK_Enrollment_Course FOREIGN KEY (CourseID) 
        REFERENCES Course(CourseID) ON DELETE CASCADE,
    CONSTRAINT FK_Enrollment_Student FOREIGN KEY (StudentID) 
        REFERENCES Student(ID) ON DELETE CASCADE,
    CONSTRAINT UQ_StudentCourse UNIQUE (StudentID, CourseID)
);
```

**Business Rules:**
- Grade is optional (student may be enrolled but not yet graded)
- Unique constraint on (StudentID, CourseID) prevents duplicate enrollments
- Cascade delete: Removing student or course deletes enrollments

**Relationships:**
- Many-to-One: Enrollment → Course
- Many-to-One: Enrollment → Student

#### 5. Department

**Purpose:** Academic department entity with concurrency control  
**Table:** `Department`  
**Location:** `ContosoUniversity/Models/Department.cs`

**Entity Definition:**
```csharp
public class Department
{
    public int DepartmentID { get; set; }
    
    [StringLength(50)]
    [Required]
    public string Name { get; set; }
    
    [DataType(DataType.Currency)]
    [Column(TypeName = "money")]
    public decimal Budget { get; set; }
    
    [DataType(DataType.Date)]
    [DisplayFormat(DataFormatString = "{0:yyyy-MM-dd}", ApplyFormatInEditMode = true)]
    [Display(Name = "Start Date")]
    public DateTime StartDate { get; set; }
    
    public int? InstructorID { get; set; }  // Foreign key (nullable)
    
    [Timestamp]  // Optimistic concurrency control
    public byte[] RowVersion { get; set; }
    
    // Navigation properties
    [Display(Name = "Administrator")]
    public virtual Instructor Administrator { get; set; }
    public virtual ICollection<Course> Courses { get; set; }
}
```

**Database Schema:**
```sql
CREATE TABLE [dbo].[Department] (
    [DepartmentID] INT IDENTITY(1,1) PRIMARY KEY,
    [Name] NVARCHAR(50) NOT NULL,
    [Budget] MONEY NOT NULL,
    [StartDate] DATETIME2 NOT NULL,
    [InstructorID] INT NULL,
    [RowVersion] ROWVERSION NOT NULL,  -- Automatically managed by SQL Server
    CONSTRAINT FK_Department_Instructor FOREIGN KEY (InstructorID) 
        REFERENCES Instructor(ID)
);
```

**Concurrency Control:**
- `RowVersion` is a SQL Server `ROWVERSION` (timestamp) column
- Automatically updated on every row change
- Used for optimistic concurrency: Update fails if RowVersion changed
- Prevents lost updates in concurrent scenarios

**Relationships:**
- Many-to-One: Department → Instructor (as Administrator)
- One-to-Many: Department → Courses

### Entity Relationships

#### ContosoUniversity Entity Relationship Diagram (Text Format)

```
Person (Abstract Base Class)
├── Student
│   └── Has Many: Enrollments
│
└── Instructor
    ├── Has Many: CourseAssignments
    ├── Has One: OfficeAssignment (optional)
    └── Administers: Departments (as Administrator)

Department
├── Belongs To: Instructor (Administrator, optional)
└── Has Many: Courses

Course
├── Belongs To: Department
├── Has Many: Enrollments
├── Has Many: CourseAssignments
└── Has One: TeachingMaterialImagePath (file reference)

Enrollment (Junction)
├── Belongs To: Student
├── Belongs To: Course
└── Has Property: Grade (nullable enum)

CourseAssignment (Junction)
├── Belongs To: Instructor
└── Belongs To: Course

OfficeAssignment
└── Belongs To: Instructor (one-to-one, shared PK)
```

#### Relationship Cardinalities

**One-to-Many:**
- Student → Enrollments (1:N)
- Course → Enrollments (1:N)
- Department → Courses (1:N)
- Instructor → CourseAssignments (1:N)
- Course → CourseAssignments (1:N)
- Department → Instructor (as Administrator) (1:1, optional)

**Many-to-Many (via junction tables):**
- Student ↔ Course (via Enrollment)
- Instructor ↔ Course (via CourseAssignment)

**One-to-One:**
- Instructor ↔ OfficeAssignment (1:1, optional)

## Validation Rules

### Java (Bean Validation)

**Annotations:**
- `@NotNull` - Field cannot be null
- `@NotBlank` - String cannot be null, empty, or whitespace
- `@Size(min=, max=)` - String/collection length constraints
- `@Min`, `@Max` - Numeric range validation
- `@Email` - Email format validation
- `@Pattern(regexp=)` - Regular expression validation

**Example (TodoItem):**
```java
@NotBlank(message = "Title is required")
@Size(max = 200, message = "Title must be less than 200 characters")
private String title;
```

---

### C# (Data Annotations)

**Attributes:**
- `[Required]` - Field cannot be null
- `[StringLength(max, MinimumLength=min)]` - String length constraints
- `[Range(min, max)]` - Numeric range validation
- `[RegularExpression(pattern)]` - Pattern matching
- `[DataType(DataType.X)]` - Data type hints (Date, Currency, Email, etc.)
- `[DisplayFormat]` - Display formatting
- `[Display(Name=)]` - UI display name

**Example (Student):**
```csharp
[Required]
[StringLength(50, MinimumLength = 1)]
[Display(Name = "First Name")]
public string FirstMidName { get; set; }
```

## Migration Considerations

### Schema Evolution
- **Adding Fields:** Use nullable columns or provide defaults
- **Removing Fields:** Drop columns after code deployment
- **Renaming Fields:** Use `@Column(name=)` or `[Column]` for mapping
- **Type Changes:** May require data migration scripts

### ORM Migration Tools
- **Java:** Flyway, Liquibase, Hibernate schema generation
- **C#:** Entity Framework Migrations (`Add-Migration`, `Update-Database`)

### Data Integrity
- Foreign key constraints ensure referential integrity
- Unique constraints prevent duplicates
- Check constraints enforce business rules
- Cascade delete options manage related data cleanup
